# Laravel Event API

REST API sviluppata con **Laravel** per la gestione di eventi, utenti e biglietti.

## Funzionalità

* Gestione degli eventi
* Gestione dei tipi di biglietto
* Gestione dei biglietti
* Gestione degli utenti
* API REST con Controllers e Resources
* Eager Loading delle relazioni
* API Resources per la trasformazione dei dati
* Factory per la generazione di dati di test

## Stack

* PHP
* Laravel
* MySQL
* Eloquent ORM

## Struttura

Il progetto utilizza principalmente:

* **Models** → gestione dei dati e delle relazioni
* **Controllers** → gestione delle richieste HTTP
* **API Resources** → trasformazione delle risposte
* **Factories** → generazione di dati di test

## Stato

Progetto in sviluppo e utilizzato per approfondire Laravel e la progettazione di API REST.
